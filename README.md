# そら — 天気予報Webアプリ

`weather.html` をブラウザーで開いて使う、iPhone利用を意識した天気予報アプリです。ビルド手順はありません。地図表示にはLeafletをCDNから読み込みます。

## 現在の機能

- 起動時に現在地を取得し、天気予報を読み込みます。位置情報が使えない場合は、前回の場所または東京を表示します。
- 現在地や検索した場所の市区町村名を、読み込み状態やエラーとは別に画面上部へ表示します。
- 保存済みの予報があれば先に表示し、起動時と更新ボタンの操作時に最新データを取得します。
- 「現在地」へ切り替え、選択中の場所を名前付きで最大6件まで登録・再選択・解除できます。主要都市は組み込み候補から直接選べます。
- 地名は2文字以上の入力中に日本国内の候補を表示します。矢印キーで候補を移動し、Enterで選択できます。長岡京市など一部のよく使う地域は組み込み候補からすぐ選べます。
- 1時間天気、雨雲レーダー、日数タブで切り替える1週間・2週間天気の順に表示します。iPhoneでは最初の1時間天気とレーダーをコンパクトに配置します。
- 時間別の天気・気温・風向・風速はJMAモデル由来、降水確率と日別の最大・最低気温はOpen-Meteoの予報を表示します。週間予報では時間別データがある7日目まで0・6・12・18時ごろの天気アイコンを並べ、今日の経過済みアイコンはグレーアウトします。日付は「月日(曜日)」で固定幅に表示し、気温レンジには現在気温を示す縦線を重ねます。
- 雨雲レーダーは淡色の地図に降水レイヤーを重ねます。全画面表示に切り替えられ、初期表示はズーム11です。広域ズームで雨雲が消えるのを避けるためズーム4を下限にしています。実況・短時間の雨雲予測から、気象庁の降水短時間予報による15時間先までを時間選択・再生できます。目盛りは過去3時間から15時間後まで固定し、再生ボタンを軸の左に置きます。現在時刻はスライダー上側に表示し、軸下側には現在・1・3・6・9・12・15時間後を示します。先の時間は1時間降水量予報として区別します。

- 2週間表示の8日目以降には「長期目安」を付けます。予報元のOpen-Meteoは気象庁の公式A/B/C信頼度とは別データのため、正式な確度スコアは表示しません。

## 起動方法

`weather.html` をブラウザーで開きます。位置情報はブラウザーの許可が必要です。iPhoneで公開して使う場合は、HTTPSで配信してください。ローカルの `file://` URLはiPhoneから開けません。GitHub Pagesを使う場合は、リポジトリの **Settings → Pages** で `main` ブランチのルートを公開元に設定し、公開後に `https://anakahama-dev.github.io/ai-agent-lab/weather.html` をiPhoneのSafariで開きます。公開設定が済んでいない場合、このURLは利用できません。

## 現在のデータソースと位置情報

- 天気・気温・風：JMA MSM/GSMモデルをOpen-Meteo経由で取得
- 降水確率：Open-Meteo Forecast API（Best Match）
- 市区町村名：HeartRails Geo API。国土交通省の位置参照情報を加工したデータを利用します。
- 地名候補：Open-Meteo Geocoding API。検索候補は日本国内に限定します。
- 雨雲・降水予報：気象庁高解像度降水ナウキャストと降水短時間予報の画像タイル。背景地図は国土地理院タイル。
- 日別予報：Open-Meteo Forecast API。最大14日分を表示します。[予報日数の仕様](https://open-meteo.com/en/docs)

現在地を使う場合、緯度・経度は天気予報と市区町村名の取得先へ送信されます。最後に使った場所と予報キャッシュはブラウザーの `localStorage` に保存されます。位置情報を許可しない場合は、都市検索を利用できます。

天気・気温・風は気象庁のJMAモデルをOpen-Meteo経由で取得します。気象庁の公式サイトから直接取得しているわけではありません。降水確率はOpen-Meteo Forecast APIのBest Matchから取得し、JMAモデルの値とは分けています。気象庁データを直接使う経路と、降水確率の公式データ化は今後の検討項目です。詳しくは[改修計画](WEATHER_PLAN.md)を参照してください。

雨雲地図は、気象庁ホームページが配信する高解像度降水ナウキャストと降水短時間予報の画像を地図に重ねます。降水短時間予報は実況の雨雲をそのまま移動させたものではなく、先の時間では数値予報も使った1時間降水量の予測です。時刻一覧と画像タイルの取得に気象庁ページ内で使われる配信経路を利用しているため、気象庁側の変更で動作しなくなる可能性があります。取得できない場合は、気象庁の公式画面を別タブで開けます。地図の出典は画面上に表示します。

地図表示にはLeafletを使用します。起動時は天気の初期表示を優先し、その後に地図ライブラリとレーダーデータを読み込みます。アプリ本体は引き続き単一のHTMLファイルです。

## 開発とバージョン管理

- `main` は共有・動作確認済みの基準として扱います。
- 今後のデータ取得機能のように複数ファイルへ広がる変更は、作業ブランチで進めます。
- 小さなまとまりごとに差分を確認し、機能単位の短いコミットメッセージで記録します。
- APIキーや個人の位置情報、取得した気象データの大量スナップショットはリポジトリに含めません。
- push前に `git status` とコミット内容を確認します。
